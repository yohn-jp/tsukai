# Tsukai 0.2.2

Tsukai 0.2.2 is the first publishable release of the post-M5.5 public contract described in the [0.2.0 release notes](0.2.0.md). `v0.2.0` and `v0.2.1` were tagged but never reached npm. The public API is unchanged from 0.2.0.

- `v0.2.0` failed before publication because the consumer-owned certification gate was missing (added in 0.2.1, see the [0.2.1 release notes](0.2.1.md)).
- `v0.2.1` passed the gate, build, and smoke test, but npm rejected the publish (E422): npm Trusted Publishing provenance requires `package.json` `repository.url` to match the GitHub repository, and it was empty.

## Changes

- Add `repository`, `homepage`, and `bugs` to `package.json`.
- Bump the package and CLI version to 0.2.2.

## Certification

The certification record is unchanged from [0.2.1](0.2.1.md#certification): no code changed. `PASSED` is recorded only for a lane that was run in the authoring environment; lanes that need a Jinushi supervisor were not re-run and are recorded `ENVIRONMENT_BLOCKED`. Update this table from a live environment before tagging if a lane has been re-run.

| Lane              | Status              | Evidence                                                                                                        |
| ----------------- | ------------------- | --------------------------------------------------------------------------------------------------------------- |
| `certify:pi`      | PASSED              | Credential-free lane against `@earendil-works/pi-coding-agent@0.99.1`; the provider-backed lane is not enabled. |
| `certify:jinushi` | ENVIRONMENT_BLOCKED | Needs a Jinushi supervisor; see [M1b](../M1B-JINUSHI.md).                                                       |
| `certify:owner`   | ENVIRONMENT_BLOCKED | Needs a Jinushi supervisor; see [M2](../M2-OWNER.md).                                                           |
| `certify:agent`   | ENVIRONMENT_BLOCKED | Needs a Jinushi supervisor; see [M3](../M3-AGENT.md).                                                           |
| `certify:harness` | ENVIRONMENT_BLOCKED | Needs a Jinushi supervisor and Claude Code; see [M5](../M5-HARNESS.md).                                         |
| `certify:profile` | ENVIRONMENT_BLOCKED | Needs a Jinushi supervisor; see [M5.5](../M5.5-PROFILE.md).                                                     |

## Install

```bash
npm install tsukai@0.2.2
```

Publication happens through `.github/workflows/publish.yml` (npm Trusted Publishing) when a GitHub Release tagged `v0.2.2` is published.
