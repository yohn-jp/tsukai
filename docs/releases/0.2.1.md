# Tsukai 0.2.1

Tsukai 0.2.1 is the first publishable release of the post-M5.5 public contract described in the [0.2.0 release notes](0.2.0.md). `v0.2.0` was tagged but never reached npm: the shared publish workflow runs a consumer-owned certification gate, and Tsukai did not yet provide `scripts/verify-release-certification.mjs`, so the release failed before publication. The public API is unchanged from 0.2.0.

## Changes

- Add `scripts/verify-release-certification.mjs`, the release certification gate. It fails closed unless all of the following hold for the exact release tarball:
  - the tarball digest equals the packed digest, and its `package.json` name and version match the tag and the source `package.json`;
  - this release note has a `## Certification` section with a `PASSED` or `ENVIRONMENT_BLOCKED` row for every `certify:*` script;
  - the latest completed `ci.yml` run for the release source commit concluded `success`.
- `ENVIRONMENT_BLOCKED` lanes are reported as warnings; they are never treated as passed. The gate never modifies the tarball.
- Add `tsx` as an exact-version development dependency; the shared workflow runs the gate with `node --import tsx`.
- Bump the package and CLI version to 0.2.1.

## Install

```bash
npm install tsukai@0.2.1
```

## Release verification

The same packed tarball is verified before publication: `pnpm run test:package` installs it into a clean consumer, the certification gate above runs against it, and `scripts/smoke-test.mjs` checks the CLI version and the exports Mottainai (M6) needs. Publication happens through `.github/workflows/publish.yml` (npm Trusted Publishing) when a GitHub Release tagged `v0.2.1` is published.
