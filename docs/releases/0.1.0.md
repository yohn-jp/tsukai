# Tsukai 0.1.0

Tsukai 0.1.0 is the initial npm release of the AgentRun lifecycle and observation SDK.

## Included surfaces

- AgentRun lifecycle and observation contracts.
- Mock runtime and testing helpers.
- Pi RPC integration.
- Jinushi-backed Pi execution integration.
- The `tsukai` CLI preview surface.

## Requirements

Node.js 24 or newer is required.

## Install

```bash
npm install tsukai@0.1.0
```

## Release verification

The release workflow builds and tests the source, packs the exact npm tarball, installs and exercises that tarball in an isolated consumer, and publishes through the organization reusable npm workflow using npm Trusted Publishing/OIDC after the package's initial npm bootstrap publication.
